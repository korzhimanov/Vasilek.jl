Vasilek.Collisions.BGK — Type
BGK(τ; conservative = true)

Relaxation towards the local Maxwellian on timescale τ: the exact solution of ∂f/∂t = (M − f)/τ with M held fixed over the step,

dest = src·exp(−Δt/τ) + (1 − exp(−Δt/τ))·M.

conservative = true (the default) takes M as the discrete Maxwellian of the line (Mieussens, Math. Models Methods Appl. Sci. 10, 1121 (2000)): the function exp(a + bv + cv²) whose density, momentum and energy, summed on the grid with the cell widths the advection schemes conserve,

Σᵢ wᵢ fᵢ (1, vᵢ, vᵢ²),   w = (v₂ − v₁, (v₃ − v₁)/2, …, vₙ − vₙ₋₁),

equal those of src. It is found by Newton's method on the convex dual, starting from the continuous Maxwellian, so collide! conserves all three to round-off on any grid and any window, and a sampled Maxwellian is a fixed point.

conservative = false samples the continuous Maxwellian of the trapezoid moments, as the operator did before 0.2. It conserves only as far as the window holds the Maxwellian's tails: a line relaxed on ±4 lost 0.8% of its density and 7% of its energy where ±8 lost 1e-6.

An empty line (n ≤ 0) and one colder than the grid resolves (T < Δv², which includes a single-node spike) are returned unchanged. So is a line whose moments no exp(a + bv + cv²) on the grid can match, where Newton does not converge: all of the mass on the two end nodes is one, with T at the largest the window allows. Leaving one such line alone conserves everything; throwing would end a whole vlasov_poisson run over a single column.

Vasilek.Collisions.Landau1P — Type
Landau1P(A; L = 20.0, Tₜ = 1.0)

The Landau collision operator in one velocity dimension, the two transverse ones a Maxwellian bath at Tₜ > 0, by default thermal:

∂f/∂t = −∂F/∂v,  F(v) = L·A ∫ Φ(v − v′) [f ∂f′ − f′ ∂f − f f′ (v − v′)/Tₜ] dv′,
Φ(u) = 2Tₜ/(u² + 2Tₜ)^(3/2),

where A = 4πe⁴N₀/(m²v₀³ω) and L is the Coulomb logarithm. Φ closes the transverse u⊥² with 2Tₜ; both particles' Maxwellians would give 4Tₜ. That sets the kernel's width, not the equilibrium: the Maxwellian at Tₜ is stationary, other temperatures relax to it, density and momentum are conserved, and the entropy relative to that Maxwellian does not increase.

On the grid F is taken at the half-points from f½ = (fᵢ + fᵢ₊₁)/2, f′½ = (fᵢ₊₁ − fᵢ)/(vᵢ₊₁ − vᵢ) and the nodal fⱼ, f′ⱼ weighted by the cell widths wⱼ, is zero at the ends, and destᵢ = srcᵢ − Δt (Fᵢ₊½ − Fᵢ₋½)/wᵢ. So Σ w f is conserved to round-off, momentum to O(Δv²) and exactly on a uniform grid while f vanishes at the ends; the Maxwellian at Tₜ is stationary to O(Δv²), and the relative entropy falls until f is that close. The grid must resolve the bath: Tₜ < Δv² is refused, Δv the coarsest spacing, tails included, and f stays positive from about Tₜ ≥ 4Δv². Forward Euler is stable for Δt ≲ δv²/(4·L·A·max f), δv the finest spacing and max f over the run. O(n²) a step. Not exported.

Vasilek.Collisions._discrete_maxwellian! — Method
_discrete_maxwellian!(M, f, v)

Write into M the discrete Maxwellian of f on v, or return false when the line has none to relax to. In the variable ξ = (v − u)/√T the target is M = exp(α₀ + α₁ξ + α₂ξ²) with Σ w M (1, ξ, ξ²) = Σ w f (1, ξ, ξ²) = ρ, the minimum of the convex Φ(α) = Σ w exp(α·φ) − α·ρ. Newton with a backtracking line search, from the continuous Maxwellian α = (log(n/√(2πT)), 0, −1/2); on a resolved line it takes two or three steps.

Vasilek.Collisions._validate_collide — Method
_validate_collide(dest, src, op, v, ws)

The argument check at the top of every six-argument collide!. Each of these gave a wrong answer, or an error from the wrong place, before it was checked:

  • dest, src and v of different lengths, or not one-based;
  • a workspace whose buffers are not the lengths workspace(op, length(v)) gives them: a shorter one threw a BoundsError once the step was computed, after Landau1P's O(n²) loop, and a longer Landau1P one ran;
  • a workspace narrower than the data, which the operator computes into: a Float32 one, as workspace(BGK(0.5f0), n) is, rounded a Float64 line's Maxwellian to Float32, 9.4e-9 off;
  • dest, src or v sharing memory with the workspace, which the operator writes while it reads src and v and before it writes dest;
  • dest sharing memory with src other than as src itself: Landau1P writes dest[i] before it reads src[i+1], and dest one node on from src in the same array came back 1.005 off. dest may be src itself, and the step is taken in place;
  • dest sharing memory with v, which Landau1P reads while it writes dest: 1.6e-4 off with dest the nodes themselves.

An operator's workspace type has a method of _scratch_lengths, _scratch_eltype, _scratch_aliases and _err_scratch_alias. The checks are comparisons outside the loop and allocate nothing; the error paths are @noinline.

Vasilek.Collisions.collide! — Method
collide!(dest, src, op, v, Δt[, ws])

Advance the velocity line src, sampled at the nodes v, by a time Δt under the collision operator op, and write the result into dest, which is returned. dest, src and v have the same length.

ws is scratch from workspace(op, length(v), float(eltype(src))), one per task: its buffers of the lengths that call gives them, its type no narrower than the data's, and sharing no memory with dest or src, which _validate_collide checks. Without it a workspace of that type is allocated for the call; pass one in any loop.

Vasilek.workspace — Function
workspace(op, n[, T])

Scratch for op at n velocity points, of the operator's element type unless T is given, or nothing. collide! refuses one narrower than the data, so Float64 data under BGK(0.5f0) needs workspace(op, n, Float64); the five-argument collide! builds its own in the data's type.
